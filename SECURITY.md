# Seguridad

## Versiones soportadas

| Versión | Soporte |
|---------|---------|
| 0.1.x (última publicada) | ✅ Soportada |
| < 0.1.x | ❌ Sin soporte |

Solo la versión más reciente publicada recibe correcciones de seguridad. Si usas una versión anterior, actualiza antes de reportar.

## Reportar una vulnerabilidad

Si descubres una vulnerabilidad en Nexo UI Kit, repórtala de forma privada usando **GitHub Security Advisories** del repositorio:

[https://github.com/NexoDigital-Lab/nexo-ui-kit/security/advisories/new](https://github.com/NexoDigital-Lab/nexo-ui-kit/security/advisories/new)

**No abras un issue público** para vulnerabilidades no parchadas.

Incluye en el reporte:

- Descripción de la vulnerabilidad y su impacto potencial.
- Pasos para reproducirla (versión, entorno, código de ejemplo).
- Cualquier corrección propuesta, si la tienes.

## Tiempo de respuesta

- Confirmación del reporte: dentro de 72 horas hábiles.
- Evaluación inicial y plan de corrección: dentro de 7 días.
- Parche o mitigación: según la gravedad; las vulnerabilidades críticas se priorizan.

Te mantendremos informado del estado del reporte durante el proceso.

## Alcance

Nexo UI Kit es una **biblioteca de componentes de interfaz** estática (Astro, sin backend):

- **En alcance**: código de los componentes, tokens, estilos y scripts incluidos en el paquete; dependencias del proyecto que puedan afectar a quien consuma el kit.
- **Fuera de alcance**: aplicaciones construidas con el kit (incluida la app Nexo Digital), infraestructura de terceros, usuarios finales o datos personales — el kit no almacena ni procesa datos de usuarios.

## Agradecimientos

Agradecemos la divulgación responsable. Si tu reporte mejora la seguridad del proyecto, lo reconoceremos en la medida de lo posible (con tu consentimiento).
